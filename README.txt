Projet Pycalc

Le projet pycalc est une calculatrice qui ne réalise que 
les quatres opérations de bases : addition, soustraction, multiplication
et division et elle renvoie le résultat.

Pour utiliser pycalc dans un terminal, il faut utiliser la commande : 
Python.exe .\pycalc.py {paramètre 1} {paramètre 2} {paramètre 3}

Les paramètres 1 et 3 correspondent aux deux nombres de l'opération, ils 
peuvent être des int ou des float.
Le paramètre 2 est le signe de l'opération : +, -, * ou / .
